# @bhedanikhilkumar-code/privex

Privacy-First, On-Device Cybersecurity & Digital-Threat Protection Engine CLI.

## Quick Start

```bash
npx @bhedanikhilkumar-code/privex scan-url "http://192.168.1.1/login"
```

```bash
npx @bhedanikhilkumar-code/privex scan-text "Urgent: Send 0.5 BTC to avoid account suspension!"
```

## Features
- **100% On-Device:** No cloud dependencies or sensitive user data transmission.
- **Sub-millisecond Detection:** Lexical analysis, bloom filters, and Shannon entropy.
- **Fail-Closed Architecture:** Robust error isolation and security invariants.
